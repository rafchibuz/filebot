# 🎬 Руководство по настройке Twitch Clips Aggregator

## 📋 Что это такое?

Это веб-приложение для агрегации клипов популярных стримеров Twitch в одном месте с возможностью сортировки по времени создания. Идеально подходит для создания видеонарезок с лучшими моментами.

## 🎯 Возможности

✅ **Агрегация клипов** - Все клипы ваших любимых стримеров в одном месте  
✅ **Сортировка по времени** - Хронологический просмотр всех клипов  
✅ **Фильтрация** - По стримеру, периоду времени, популярности  
✅ **Автообновление** - Новые клипы загружаются автоматически  
✅ **Встроенный плеер** - Просмотр без перехода на Twitch  
✅ **Статистика** - Аналитика по клипам и стримерам  

## 🚀 Быстрая установка

### Шаг 1: Скачайте и запустите установку
```bash
# Если у вас есть git
git clone <your-repo-url>
cd twitch-clips-aggregator

# Или просто распакуйте архив и перейдите в папку

# Запустите автоматическую установку
./install-and-run.sh
```

### Шаг 2: Получите Twitch API ключи

1. 🌐 Перейдите на [Twitch Developer Console](https://dev.twitch.tv/console/apps)
2. 🔑 Войдите в ваш аккаунт Twitch
3. ➕ Нажмите **"Register Your Application"**
4. 📝 Заполните форму:
   - **Name**: `Twitch Clips Aggregator`
   - **OAuth Redirect URLs**: `http://localhost:3000`
   - **Category**: `Analytics Tool`
5. 💾 Сохраните приложение
6. 📋 Скопируйте **Client ID** и **Client Secret**

### Шаг 3: Настройте конфигурацию

Откройте файл `.env` и замените:
```env
TWITCH_CLIENT_ID=your_client_id_here     # ← Вставьте ваш Client ID
TWITCH_CLIENT_SECRET=your_client_secret_here  # ← Вставьте ваш Client Secret
```

### Шаг 4: Настройте стримеров (опционально)

В том же файле `.env` можете изменить список отслеживаемых стримеров:
```env
STREAMERS=RavshanN,steel,renatko,your_streamer_here
```

### Шаг 5: Запустите приложение

```bash
./start.sh
```

Или вручную:
```bash
npm run dev
```

## 🌐 Использование

После запуска:
- 🖥️ **Веб-интерфейс**: http://localhost:3000
- 🔧 **API**: http://localhost:3001

### Основные функции:

1. **Просмотр клипов** - Все клипы отображаются в виде карточек с превью
2. **Фильтрация** - Используйте панель фильтров для настройки отображения
3. **Воспроизведение** - Нажмите на клип для просмотра во встроенном плеере
4. **Ссылки** - Переход к оригинальному клипу на Twitch
5. **Статистика** - Просмотр аналитики по клипам и стримерам

### Параметры фильтрации:

- **Период**: от 1 дня до 1 месяца
- **Стример**: выбор конкретного стримера или всех
- **Мин. просмотров**: фильтр по популярности
- **Сортировка**: по времени, просмотрам или названию
- **Порядок**: по возрастанию или убыванию

## 🔧 Расширенная настройка

### Изменение интервала обновления
В `.env` файле:
```env
UPDATE_INTERVAL=30  # минуты между автоматическими обновлениями
```

### Настройка порта
```env
PORT=3001  # порт для API сервера
```

### Настройка базы данных
```env
DB_PATH=./data/clips.db  # путь к файлу базы данных
```

## 🛠 Разработка

### Структура проекта
```
├── server/           # Backend (Node.js + Express + SQLite)
├── client/           # Frontend (React + Material-UI)
├── data/            # База данных SQLite
└── .env             # Конфигурация
```

### Команды разработчика
```bash
npm run server       # Только сервер
npm run client       # Только клиент  
npm run dev          # Сервер + клиент
npm run build        # Production сборка
```

## 🐛 Устранение проблем

### Ошибка "API ключи не настроены"
- Проверьте файл `.env`
- Убедитесь, что заменили `your_client_id_here` и `your_client_secret_here`

### Ошибка "Клипы не загружаются"
- Проверьте интернет соединение
- Убедитесь, что API ключи корректны
- Проверьте, что стримеры существуют на Twitch

### Порт уже занят
- Измените `PORT` в `.env` файле
- Или остановите процесс, использующий порт 3001
