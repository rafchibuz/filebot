# Twitch Clips Aggregator

Веб-приложение для агрегации и просмотра популярных клипов нескольких стримеров Twitch с сортировкой по времени создания.

## 🎯 Особенности

- **Агрегация клипов** от нескольких стримеров в одном месте
- **Сортировка по времени создания** для удобного просмотра хронологии
- **Фильтрация** по стримеру, периоду времени и количеству просмотров
- **Автоматическое обновление** клипов каждые 30 минут
- **Современный UI** с темной темой в стиле Twitch
- **Встроенный плеер** для просмотра клипов без перехода на Twitch
- **Статистика** по клипам и стримерам

## 🚀 Быстрый старт

### 1. Настройка Twitch API

1. Перейдите на [Twitch Developer Console](https://dev.twitch.tv/console/apps)
2. Создайте новое приложение
3. Получите `Client ID` и `Client Secret`

### 2. Установка и настройка

```bash
# Клонируйте репозиторий и перейдите в папку
cd twitch-clips-aggregator

# Установите зависимости
npm run install-all

# Создайте файл .env на основе .env.example
cp .env.example .env

# Отредактируйте .env файл, добавив ваши Twitch API ключи
```

### 3. Настройка .env файла

```env
# Twitch API Configuration
TWITCH_CLIENT_ID=your_client_id_here
TWITCH_CLIENT_SECRET=your_client_secret_here

# Server Configuration
PORT=3001
NODE_ENV=development

# Database
DB_PATH=./data/clips.db

# Streamers Configuration (comma-separated usernames)
STREAMERS=RavshanN,steel,renatko

# Update interval in minutes
UPDATE_INTERVAL=30
```

### 4. Запуск приложения

```bash
# Запуск в режиме разработки (сервер + клиент)
npm run dev

# Или запуск только сервера
npm run server

# Или запуск только клиента
npm run client
```

Приложение будет доступно по адресу: http://localhost:3000

## 🔧 API Endpoints

- `GET /api/clips` - Получение клипов с фильтрами
- `GET /api/clips/refresh` - Принудительное обновление клипов
- `GET /api/streamers` - Получение списка стримеров
- `GET /api/health` - Проверка состояния сервера

### Параметры фильтрации

- `daysBack` - Количество дней назад (по умолчанию: 7)
- `streamer` - Фильтр по конкретному стримеру
- `minViews` - Минимальное количество просмотров
- `sortBy` - Поле сортировки (`created_at`, `view_count`, `title`)
- `sortOrder` - Порядок сортировки (`ASC`, `DESC`)
- `limit` - Максимальное количество клипов (по умолчанию: 50)

## 🎨 Функционал

### Для пользователей
- Просмотр клипов всех настроенных стримеров в одном месте
- Фильтрация по стримеру, времени и популярности
- Встроенный видеоплеер с возможностью полноэкранного просмотра
- Ссылки на оригинальные клипы на Twitch
- Статистика по клипам и стримерам

### Для разработчиков
- Автоматическое обновление данных через Twitch API
- SQLite база данных для кэширования клипов
- RESTful API для интеграции с другими сервисами
- Настраиваемый список отслеживаемых стримеров

## 🛠 Технологии

### Backend
- **Node.js** + **Express** - веб-сервер
- **SQLite** - база данных
- **Twitch Helix API** - источник данных
- **node-cron** - автоматическое обновление

### Frontend
- **React 18** - пользовательский интерфейс
- **Material-UI** - компоненты интерфейса
- **React Player** - видеоплеер
- **date-fns** - работа с датами

## 📊 База данных

Приложение использует SQLite для хранения:
- **clips** - информация о клипах (заголовок, URL, просмотры, дата создания и т.д.)
- **streamers** - информация о стримерах (логин, отображаемое имя, аватар)

## 🔄 Автоматическое обновление

- Клипы автоматически обновляются каждые 30 минут (настраивается)
- При старте сервера загружаются клипы за последние 7 дней
- Возможность принудительного обновления через UI

## 🎯 Применение
